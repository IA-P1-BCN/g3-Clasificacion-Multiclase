Preprocesado

5. Preprocesado: preparar los datos

Variables numéricas

  1. Imputar valores ausentes con la mediana.
  2. Estandarizar para poner las variables en escalas comparables.

Variable categórica: Abbrev

  1. Imputar ausencias con la categoría más frecuente.
  2. One-hot encoding: convertir cada sitio en columnas binarias.

¿Por qué escalar? SVM es sensible a la escala: sin estandarizar, una variable con números grandes podría influir más solo por su magnitud.

Todo se integra en un Pipeline y se ajusta únicamente con train para evitar fuga de información.

Modelo

7. ¿Qué hace un SVM?

SVM significa Support Vector Machine (máquina de vectores de soporte). Es un algoritmo supervisado que busca una frontera que separe las clases.

1

Aprende

Busca una frontera de decisión a partir de ejemplos etiquetados.

2

Compara

Para una parcela nueva, analiza en qué lado de las fronteras encaja.

3

Predice

Devuelve una de las cinco categorías de Utility.

En este experimento se utiliza un SVM lineal: las fronteras de decisión son lineales en el espacio de variables preprocesadas.

Validación

8. Validación cruzada: comprobar la estabilidad

StratifiedKFold

Divide train en 5 partes (folds), conservando aproximadamente la proporción de clases.

En cada ronda entrena con cuatro partes y valida con la quinta; después promedia los resultados.

StratifiedGroupKFold

Repite la evaluación agrupando por sitio (Abbrev).

Validar por sitio ayuda a detectar si el modelo se beneficia demasiado de haber visto parcelas del mismo lugar.

ADR-0002: comparar ambas validaciones para entender el efecto del sitio.

Ajuste

9. Sobreajuste y parámetro C

Primer intento · C = 1

F1 CV = 0,568

Gap = 15,0 puntos

Supera el límite de 5: sobreajuste.

¿Qué controla C?

C regula cuánto penalizamos los errores de entrenamiento.

Un C menor hace al modelo más conservador; uno mayor permite ajustarse más a los datos de train.

Gap = F1 macro de train − F1 macro de validación. Si el resultado en train es mucho mejor, puede que el modelo esté memorizando en lugar de generalizar.

Conclusiones

¿Qué nos llevamos del experimento?

  • El SVM lineal elegido utiliza C = 0,045 y obtiene F1 macro 0,636 en validación.
  • El gap final es 3 puntos: cumple el criterio de sobreajuste inferior a 5.
  • Supera claramente al Dummy y reconoce especialmente bien good y none.
  • Su principal limitación es distinguir best de good; el vigor es la variable más influyente.
  • El test queda reservado para la comparación final de modelos.

Mensaje clave: no elegimos solo el modelo con mejor nota, sino el que equilibra rendimiento y capacidad de generalizar.
